AI Based Public Transport Load Predictor

Clean, modern UI — quick predictions using weighted scoring

This AI-driven system predicts public transport passenger load using real-time factors and historical travel data. The prediction changes dynamically based on multiple input combinations.

How inputs affect prediction
Peak times and office routes or events increase load; off-peak and residential reduce it.
Output: Predicted passenger load: Low / Medium / High / Very High

Prediction Rules (weights)
  • Route: City Center/Office +3, College +2, Residential +1
  • Day: Weekday +2, Weekend +1
  • Time: Morning/Evening +3, Afternoon +2, Night +1
  • Event: Festival/Public Holiday +4, Sports +3, No Event +0
  • Weather: Rainy +2, Extreme Heat +1, Normal +0
  • Transport: Local Train +3, Metro +2, Bus +1
Explanation of inputs & output

Inputs affect the prediction differently: peak time, office routes, and events tend to increase passenger load while off-peak times and residential routes tend to decrease it. The system uses a weighted scoring mechanism to convert these inputs into a single score which maps to four qualitative load levels.

Output Mapping: Score ≤ 6 → Low, 7–10 → Medium, 11–15 → High, >15 → Very High
